# Examination Scheduling System

A FastAPI-based web application for automated exam scheduling and management.

## Overview

This system automates the process of scheduling examinations for educational institutions, optimizing room utilization, teacher assignments, and student distribution. It provides both an API and a web interface for different user roles (administrators, teachers, and students).

## Features

- **Automated Exam Scheduling**: Generate optimal exam schedules based on configured parameters
- **Room Management**: Track and manage examination rooms and their capacity
- **Subject Management**: Manage subjects and student registrations
- **Teacher Assignment**: Automatically assign teachers as exam supervisors
- **User Management**: Support for multiple user roles (admin, teacher, student)
- **Responsive UI**: Web interface for all users to interact with the system
- **Import/Export**: Import data from Excel files and export schedules

## Technology Stack

- **Backend**: FastAPI (Python)
- **Database**: MongoDB
- **Frontend**: Jinja2 Templates, Bootstrap 5, JavaScript
- **Authentication**: JWT-based authentication
